# Jelly Customer Needs Cluster Analysis

Interactive 3-screen dashboard visualizing Jelly's positioning vs competitors in UK hospitality market.

## Features
- **Screen 1**: Jelly's 4 core clusters (Admin/Invoice, Cost/Margin, Supplier/Inventory, Multi-site Ops)
- **Screen 2**: Competitor overlay (MarketMan, KitchenCut, Nory, Jolt) 
- **Screen 3**: Interview insights + 6 whitespace opportunities (waste tracking, menu engineering, etc.)
